**Goal:** Retro sound effects (ship shot, thrust loop, enemy shot, explosion, pickup, drop-off), per-level CC0 chiptune music, and an M mute key.

**Architecture:** A Phaser-free `src/logic/audio.ts` holds the sound table and the music-switching rule (unit-tested). `src/audio/GameAudio.ts` wraps `scene.sound` with one method per game event; `LevelScene` calls it at each hook. **Tech Stack:** TypeScript (strict), Phaser 4.2.1 sound manager (Web Audio), Vite, Vitest, Playwright, Node (script), ffmpeg, Tiled 1.12 (Flatpak) via `npm run maps`.

## Review Focus

1. **Scene restart with music already playing** (next level, or replay after ALL MISSIONS COMPLETE): the same track must keep playing without restarting or doubling; a different track must replace it, never play alongside it. Pinned by Task 1's `musicAction` tests and Task 4's e2e "next level switches music" test.
2. **Audio still locked** (no key pressed yet) when the scene restarts: no second music track and no stacked `UNLOCKED` listeners. Pinned by Task 4's GameAudio design (listener removed on `SHUTDOWN`) and the e2e test that checks only one music sound exists after a restart.
3. **Thrust left droning**: ship dies, fuel runs out, banner shows or scene restarts while up is held. Pinned by Task 4's e2e "thrust stops when the level completes" test.
4. **Unknown or missing `music` property** on a map: no music, no crash. Pinned by Task 1's `musicKey` tests.
5. **Audible seam where a loop restarts** (thrust WAV, MP3 encoder padding on the music): checked by ear in the controller's browser pass; Task 2's crossfade handles thrust.

```ts
/** A sound the game loads: its key, its file under assets/, its volume and whether it loops. */
export interface SoundDef {
	key: string;
	file: string;
	volume: number;
	loop?: boolean;
}

// Volumes, tuned by ear: music sits under the effects, the thrust rumble under the shots.
const SHOT_VOLUME = 0.5;
const EXPLOSION_VOLUME = 0.6;
const BLING_VOLUME = 0.6;
const THRUST_VOLUME = 0.4;
const MUSIC_VOLUME = 0.3;

/** The sound effects, made by scripts/make-sfx.mjs. */
export const SOUNDS: readonly SoundDef[] = [
	{ key: 'ship-shot', file: 'audio/ship-shot.wav', volume: SHOT_VOLUME },
	{ key: 'enemy-shot', file: 'audio/enemy-shot.wav', volume: SHOT_VOLUME },
	{ key: 'explosion', file: 'audio/explosion.wav', volume: EXPLOSION_VOLUME },
	{ key: 'pickup', file: 'audio/pickup.wav', volume: BLING_VOLUME },
	{ key: 'drop-off', file: 'audio/drop-off.wav', volume: BLING_VOLUME },
	{ key: 'thrust', file: 'audio/thrust.wav', volume: THRUST_VOLUME, loop: true },
];

/** The music tracks a level can name in its `music` map property. See audio/CREDITS.md. */
export const MUSIC: readonly SoundDef[] = [
	{ key: 'music-stargazer', file: 'audio/music-stargazer.mp3', volume: MUSIC_VOLUME, loop: true },
	{ key: 'music-spaceshooter', file: 'audio/music-spaceshooter.mp3', volume: MUSIC_VOLUME, loop: true },
];

export type MusicAction = 'keep' | 'start' | 'switch' | 'stop' | 'none';

/** What to do with the music when a level starts, given the track playing and the one the level wants. */
export function musicAction(playingKey: string | null, wantedKey: string | null): MusicAction {
	if (playingKey === wantedKey) {
		return playingKey ? 'keep' : 'none';
	}
	if (!playingKey) {
		return 'start';
	}
	return wantedKey ? 'switch' : 'stop';
}

/** The value if it names a MUSIC track, else null (no music). */
export function musicKey(value: string): string | null {
	return MUSIC.some((m) => m.key === value) ? value : null;
}

/** The volume of a sound or track; 1 for a key in neither table. */
export function soundVolume(key: string): number {
	return [...SOUNDS, ...MUSIC].find((s) => s.key === key)?.volume ?? 1;
}
```

- [ ] **Step 1: Write the script**

`scripts/make-sfx.mjs`:

```js
#!/usr/bin/env node
// Synthesize the game's retro (sfxr-style) sound effects into public/assets/audio/*.wav.
// Deterministic: noise comes from a seeded PRNG, so re-running gives the same files.
// Tweak a sound's entry in SOUNDS and run `npm run sfx` again.
import { mkdirSync, writeFileSync } from 'node:fs';
import { dirname, join } from 'node:path';
import { fileURLToPath } from 'node:url';

const RATE = 44100;
const OUT = join(dirname(fileURLToPath(import.meta.url)), '..', 'public', 'assets', 'audio');

/** xorshift32: a small seeded PRNG giving 0..1. */
function prng(seed) {
	let s = seed >>> 0 || 1;
	return () => {
		s ^= s << 13; s >>>= 0;
		s ^= s >>> 17;
		s ^= s << 5; s >>>= 0;
		return s / 4294967296;
	};
}

/**
 * One voice: a wave at a frequency sliding from `freq` to `freqEnd` (Hz) over `duration` (s),
 * shaped by a linear attack and an exponential-ish decay. `steps` (Hz list) instead plays notes
 * in equal slices (an arpeggio). Noise is sample-and-hold, refreshed at the voice's frequency.
 */
function voice({ wave, duration, freq = 440, freqEnd = freq, steps, attack = 0.005, decay = 1, duty = 0.5, gain = 1, seed = 1 }) {
	const n = Math.round(duration * RATE);
	const out = new Float32Array(n);
	const rand = prng(seed);
	let phase = 0;
	let held = 0;
	for (let i = 0; i < n; i++) {
		const t = i / n;
		const f = steps ? steps[Math.min(steps.length - 1, Math.floor(t * steps.length))] : freq * Math.pow(freqEnd / freq, t);
		const prev = phase;
		phase = (phase + f / RATE) % 1;
		let s;
		switch (wave) {
			case 'square': s = phase < duty ? 1 : -1; break;
			case 'saw': s = 2 * phase - 1; break;
			case 'triangle': s = 1 - 4 * Math.abs(phase - 0.5); break;
			case 'noise': if (phase < prev) held = rand() * 2 - 1; s = held; break;
			default: throw new Error(`unknown wave ${wave}`);
		}
		const time = i / RATE;
		const env = Math.min(1, time / attack) * Math.pow(1 - t, decay);
		out[i] = s * env * gain;
	}
	return out;
}

/** One-pole low-pass filter; `cutoff` in Hz. */
function lowpass(samples, cutoff) {
	const a = 1 - Math.exp((-2 * Math.PI * cutoff) / RATE);
	let y = 0;
	return samples.map((x) => (y += a * (x - y)));
}

/** Sum voices (padding the shorter ones with silence). */
function mix(...parts) {
	const out = new Float32Array(Math.max(...parts.map((p) => p.length)));
	for (const p of parts) p.forEach((v, i) => { out[i] += v; });
	return out;
}

/** Make a seamless loop: crossfade the last `fade` seconds into the start, then drop them. */
function seamless(samples, fade) {
	const f = Math.round(fade * RATE);
	const out = samples.slice(0, samples.length - f);
	for (let i = 0; i < f; i++) {
		const w = i / f;
		out[i] = out[i] * w + samples[samples.length - f + i] * (1 - w);
	}
	return out;
}

/** Scale so the peak is `peak` of full scale. */
function normalize(samples, peak = 0.9) {
	const max = samples.reduce((m, v) => Math.max(m, Math.abs(v)), 0) || 1;
	return samples.map((v) => (v / max) * peak);
}

function wav(samples) {
	const data = Buffer.alloc(samples.length * 2);
	samples.forEach((v, i) => data.writeInt16LE(Math.round(Math.max(-1, Math.min(1, v)) * 32767), i * 2));
	const h = Buffer.alloc(44);
	h.write('RIFF', 0); h.writeUInt32LE(36 + data.length, 4); h.write('WAVE', 8);
	h.write('fmt ', 12); h.writeUInt32LE(16, 16); h.writeUInt16LE(1, 20); h.writeUInt16LE(1, 22);
	h.writeUInt32LE(RATE, 24); h.writeUInt32LE(RATE * 2, 28); h.writeUInt16LE(2, 32); h.writeUInt16LE(16, 34);
	h.write('data', 36); h.writeUInt32LE(data.length, 40);
	return Buffer.concat([h, data]);
}

const SOUNDS = {
	// Short square blip, falling pitch.
	'ship-shot': () => voice({ wave: 'square', duration: 0.14, freq: 1400, freqEnd: 350, decay: 1.5, duty: 0.5 }),
	// Low, buzzy saw shot with a touch of noise: unlike the ship's.
	'enemy-shot': () => mix(
		voice({ wave: 'saw', duration: 0.22, freq: 520, freqEnd: 160, decay: 1.2 }),
		voice({ wave: 'noise', duration: 0.08, freq: 6000, decay: 2, gain: 0.3, seed: 7 }),
	),
	// Noise burst whose grain slows as it decays.
	explosion: () => lowpass(voice({ wave: 'noise', duration: 0.7, freq: 4000, freqEnd: 300, attack: 0.002, decay: 2.2, seed: 3 }), 3000),
	// Rising two-note bling.
	pickup: () => voice({ wave: 'square', duration: 0.18, steps: [988, 1319], decay: 0.6, duty: 0.25 }),
	// Brighter rising three-note arpeggio.
	'drop-off': () => mix(
		voice({ wave: 'square', duration: 0.3, steps: [1047, 1319, 1568], decay: 0.5, duty: 0.25 }),
		voice({ wave: 'triangle', duration: 0.3, steps: [2094, 2638, 3136], decay: 0.8, gain: 0.3 }),
	),
	// ~1 s low rumble, constant level (no envelope), crossfaded so it loops without a click.
	thrust: () => seamless(lowpass(voice({ wave: 'noise', duration: 1.1, freq: 2500, attack: 0.0001, decay: 0, seed: 11 }), 500), 0.1),
};

mkdirSync(OUT, { recursive: true });
for (const [name, make] of Object.entries(SOUNDS)) {
	const samples = normalize(make());
	writeFileSync(join(OUT, `${name}.wav`), wav(samples));
	console.log(`audio/${name}.wav  ${(samples.length / RATE).toFixed(2)} s`);
}
```

Notes: with `decay: 0`, `Math.pow(1 - t, 0)` is 1, so the thrust has a flat envelope; `attack: 0.0001` avoids a fade-in that would break the loop.

```ts
import Phaser from 'phaser';
import { MUSIC, musicAction, soundVolume } from '../logic/audio.ts';

const isMusic = (sound: Phaser.Sound.BaseSound): boolean => MUSIC.some((m) => m.key === sound.key);

/**
 * The game's sounds, one method per event. The sound manager belongs to the game, not the scene,
 * so music carries on across scene restarts; the thrust loop belongs to this scene and is
 * destroyed when it shuts down.
 */
export class GameAudio {
	sound: Phaser.Sound.BaseSoundManager;
	thrustLoop: Phaser.Sound.BaseSound;
	/** Set while music waits for the browser to allow audio; removed if the scene shuts down first. */
	pendingMusic: (() => void) | undefined;

	constructor(scene: Phaser.Scene) {
		this.sound = scene.sound;
		this.thrustLoop = this.sound.add('thrust', { loop: true, volume: soundVolume('thrust') });
		scene.events.once(Phaser.Scenes.Events.SHUTDOWN, () => {
			this.thrustLoop.destroy(); // stops it too
			if (this.pendingMusic) {
				this.sound.off(Phaser.Sound.Events.UNLOCKED, this.pendingMusic);
				this.pendingMusic = undefined;
			}
		});
	}

	play(key: string): void {
		this.sound.play(key, { volume: soundVolume(key) });
	}

	shipShot(): void { this.play('ship-shot'); }
	enemyShot(): void { this.play('enemy-shot'); }
	explosion(): void { this.play('explosion'); }
	pickup(): void { this.play('pickup'); }
	dropOff(): void { this.play('drop-off'); }

	/** Keep the thrust loop running while `on`; start and stop it only on a change. */
	thrust(on: boolean): void {
		if (on && !this.thrustLoop.isPlaying) {
			this.thrustLoop.play();
		} else if (!on && this.thrustLoop.isPlaying) {
			this.thrustLoop.stop();
		}
	}

	/** Play the level's track (null: none), keeping the one already playing if it's the same. */
	playMusic(key: string | null): void {
		if (this.sound.locked) {
			this.pendingMusic = () => {
				this.pendingMusic = undefined;
				this.playMusic(key);
			};
			this.sound.once(Phaser.Sound.Events.UNLOCKED, this.pendingMusic);
			return;
		}
		// Every music sound, not just the playing ones: one paused by pauseOnBlur still counts.
		const playing = MUSIC.flatMap((m) => this.sound.getAll(m.key))[0];
		const action = musicAction(playing?.key ?? null, key);
		if ((action === 'switch' || action === 'stop') && playing) {
			playing.destroy();
		}
		if ((action === 'start' || action === 'switch') && key) {
			this.sound.add(key, { loop: true, volume: soundVolume(key) }).play();
		}
	}

	/** Mute or unmute everything; returns true when now muted. */
	toggleMute(): boolean {
		this.sound.mute = !this.sound.mute;
		return this.sound.mute;
	}
}
```

Notes for the implementer:
- `Phaser.Sound.BaseSoundManager`'s typings may not declare `mute` as writable or `locked`; if `tsc` complains, use `this.sound.setMute(!this.sound.mute)` on the concrete manager type (`Phaser.Sound.WebAudioSoundManager | Phaser.Sound.HTML5AudioSoundManager | Phaser.Sound.NoAudioSoundManager`, which is what `scene.sound` is typed as) and keep the rest. Check `node_modules/phaser/types/phaser.d.ts` for `locked` and `mute`.
- Only one music sound should ever exist in the manager (Review Focus 1). That is why `playMusic` looks up every music sound with `getAll(key)` (paused ones included; the manager resumes those itself on focus) and destroys, rather than stops, the old one on a switch. Drop the now-unused `isMusic` helper if lint flags it.
